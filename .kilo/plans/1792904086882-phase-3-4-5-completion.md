## Risks / Known Limitations

- **Reddit API rate limits**: PRAW handles this; need exponential backoff for 429
- **Reddit OAuth2**: Requires registered app; credentials must be managed securely (Render env vars, GitHub secrets)
- **News table schema**: Already exists (`app/models/news.py`), just needs data
- **Integration test DB**: CI needs PostgreSQL service container; may slow pipeline
- **Calculator accuracy**: Formulas from Stat Systems Guide have known bugs (shake speed 1000-1700% zone); document assumptions
