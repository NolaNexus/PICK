# PICK — Plan: Get the Project to Launch (Static GitHub Pages)

## Goal

Make `https://nolanexus.github.io/PICK/` a live, usable public site whose six pages
render wiki data from the committed `frontend/public/snapshot.json`, with the finished
Prospecting! theme applied (light mode). No live backend is required for this milestone.

## Decisions (resolved with the user)

1. **Launch surface:** static GitHub Pages frontend only. The Render API, Postgres, and
   cron jobs are **not** required for launch and must not be broken by these changes.
2. **Theme:** finish and ship the Prospecting! theme now; **light mode only** (no toggle,
   keep the `.dark` token block for later). Keep existing page layouts — no redesign.
3. **Pages delivery:** switch to the official GitHub Actions Pages flow
   (`configure-pages` + `upload-pages-artifact` + `deploy-pages`); Settings → Pages →
   Source = **GitHub Actions**.
4. **News:** ship with `news: 0`. Reddit credentials are a post-launch item.
5. **Canonical URL now:** `https://nolanexus.github.io/PICK/` → router basename `/PICK`,
   Vite `base` `/PICK/`. Custom domain `pick.helmsfirth.online` is a **post-launch** goal
   (see Phase 7); it will change basename/base when adopted.

## Phase 2 — Finish the Prospecting! theme (blocker B4)

Reference: `.kilo/plans/1793074958014-prospecting-theme-design.md` (light mode subset only).

1. `frontend/src/index.css`: the theme consumes `hsl(var(--x))`, so tokens must be HSL
   **triplets** (e.g. `45 90% 51%`), not hex.
   - Add missing tokens used by components: `--water`, `--water-foreground`, `--earth`,
     `--earth-foreground`, `--cave`, `--cave-foreground` (light values; mirror in `.dark`).
   - Convert `--rarity-*` from hex to HSL triplets so `hsl(var(--rarity-common))` in
     `frontend/src/lib/theme.ts:4-12` is valid. (Alternative: drop the `hsl()` wrapper in
     `theme.ts`; pick one and keep it consistent everywhere.)
2. `frontend/src/lib/theme.ts`: remove or convert the helpers that build **dynamic Tailwind
   arbitrary classes** at runtime (`getRarityBorder/Bg/Text`, `themeClasses`, `cardVariants`,
   `buttonVariants`, `hoverEffects`) — Tailwind cannot generate those class strings from JS
   variables. Rarity styling must use inline styles (already the pattern in `badge.tsx:7-16`
   and `card.tsx:35`). Keep only static, build-visible class strings.
3. `frontend/src/components/layout/header.tsx`: replace the `Coffee` logo/Status icon with a
   pan/shovel mark (from `@/assets/icons/prospecting` `ProspectingIcons.Pan`/`Shovel` or lucide
   `Shovel`/`Gem`); add the `/search` item to `navItems` so Search is reachable.
4. `frontend/src/assets/icons/prospecting.ts`: keep only if it is actually imported; otherwise
   delete it. If kept, it must typecheck (all named lucide imports were verified to exist).
5. Apply the defined variants (`button` gold/gem/earth, `badge` outline, `card`) to existing
   call sites only where it is a drop-in swap; do **not** restructure page layouts or add
   page-specific rarity treatments beyond what already exists.
6. `frontend/tailwind.config.js` already defines the `prospecting.*` palette, animations, and
   keyframes — verify it stays valid and that `content` globs still cover `src`.
7. No dark-mode toggle; leave `.dark` tokens in place but unused.

## Phase 4 — Pages deployment via GitHub Actions

1. Rewrite `.github/workflows/static.yml` to the official flow:
   - `on: { push: { branches: [master] }, workflow_dispatch }`.
   - `permissions: { contents: read, pages: write, id-token: write }`;
     `concurrency: { group: pages, cancel-in-progress: true }`.
   - **build** job: `actions/checkout`, `actions/setup-node` (see Node note), `npm ci --legacy-peer-deps`

     `actions/configure-pages@v5`, `actions/upload-pages-artifact@v3` with `path: frontend/dist`.
   - **deploy** job: `needs: build`, `environment: { name: github-pages, url: … }`,
     `actions/deploy-pages@v4`.
2. Remove `peaceiris/actions-gh-pages` usage; ensure `.nojekyll` stays in `frontend/public/`
   (already present) and is copied into `dist`.
3. Repo Settings → Pages → **Source: GitHub Actions** (one-time user action).
4. Ensure the `VITE_API_BASE_URL` repository secret is **unset or empty** for this milestone

5. Node version: `package.json` uses `vite ^8.3.4`, `typescript ~6.0.3`, React 19 — set the CI

## Risks

- **Node/Vite mismatch:** Vite 8 + TS 6 may reject Node 20 in CI → build fails, no deploy.
  Mitigation: verify locally, fall back to Node 22.
- **Snapshot writes blocked:** protected `master` or read-only Actions permissions stop the
  scrape jobs from pushing the snapshot → site data freezes. Mitigation: Phase 3.3.
- **Partial theme fix:** if only `--water/--earth` or only the rarity vars are fixed, some
  elements still render unstyled. Mitigation: fix tokens and consumption together (Phase 2.1–2.2).
- **Base-path drift:** any future re-introduction of a hard-coded basename (custom domain, rename)
  re-breaks routing; keep B1/B2/B3 values sourced from one place where feasible.
- **404 fallback is a script redirect:** it is the only SPA deep-link mechanism on Pages; verify
  it on the real deployed URL, not just `vite preview`.

### Additional defects found and fixed during implementation

- **Tailwind config had no shadcn token colors.** `bg-primary`, `bg-card`, `text-foreground`
  and `border-input` resolved to nothing, so most of the UI was unstyled.
- **Opacity modifiers on `hsl(var(--x))` produced invalid CSS.** Tailwind 3 emitted
  `background-color: hsl(var(--earth))/90`. Semantic colors are now literal values in the
  Tailwind config.
- **`Button` applied no variant when the prop was omitted**, leaving the five primary
  action buttons as plain text.
- **The static snapshot was not normalized**, so the Status page crashed on an undefined
  `meta` object. Both the API and static paths now go through `normalizeSnapshot`.
- **The Changelog version regex matched `=== Changelog ===`** (a level-3 heading), so the
  page title was stored and displayed as the game version.
- **`export_snapshot` always reported `changed: true`**, making the daily workflow commit
  a timestamp-only diff and redeploy the site every six hours.
- **`rpy2` is not installable without R**, but CI installed dependencies before R — this
  had failed every CI run since the project was created.
- **`greenlet==3.1.3` has no wheel** for any supported Python.
- **`prometheus_client` was imported but never declared.**
- **The health check path was wrong** (`/api/v1/health/ready` instead of
  `/api/v1/health/health/ready`), so Compose and Render would both report the service
  unhealthy.
