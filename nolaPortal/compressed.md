## GLOBAL CONVENTIONS (replaces per-table legend)
Stat prefixes on ores: L luck, C capacity, W size/weight, D dig amount, S dig speed,
$ sell boost, K walk speed, M modifier boost, A shake amount, P shake speed ("amount"="strength").
Modifier glossary: Treasured=2L, Mutated=LDM, Perfect=LCW, Voidtorn=LC, Iridescent=L, Cosmic=CA,
Lunar=SPK, Crystalline=W, Irradiated=M, Scorching=D, Electrified=SP, Shiny=A, Glowing=P.
Notation: trailing number on ore = min weight (kg) for max museum boost · `#×/#× ring` = 8-slot/6-slot
counts · `a / b / c` = alternatives in one slot, pick one unless "pick N" stated · fbk = fallback ·
† = limited-time · 🍪 = XP Cookie trigger · ‡ = Treasured impossible for this ore ·
° = stat prefix inferred by compression (flattened source cell omitted it; see discrepancy register).
Fungal Marsh (all ⚠ builds): swap one designated ring (Umbrite/Sun's Gift/RoT as noted) for Purifying Ring.
Default totems: Luck, Strength, Luminant; Friendship OK unless Solitude rune equipped.
1-tap check (in totems): DigStrength × 1.5 ≥ Capacity. Failing → push Mutated; overshooting → push Perfect.
Early forging (St 0–I): neck/charm first when merging to 6★; two 5★ rings > one 6★; day-9 Diamond
Catalyst goes on Frostthorn Pendant, not a Mythril Ring.
DMR note: blueprint/materials obtainable pre-Swamp; guides list it St III+; substitute for
Umbrite/Vortex/RoT/Mythril Ring anytime.
Sandshaking: technique of minimizing dig↔shake switching near the shore; "sandshaking tech" is a
misnomer (tech ≠ technique), not an item.

# Treasure Chests / Geodes — general
Chests: easiest source of relics/totems; ONLY source of Treasured 2L ores (best for Luck Efficiency).
Maps drop per dig. Dedicated map build needs: dig speed = 10% (Solar Rings and/or low-quality Venomshank
— lower quality, the better), Treasure Hunter shovel enchant (2× map chance, capacity 10), Excalibur
charm (Treasure Map Chance stat). Tips: dig quality irrelevant; same-location digging boosts specific
map odds; swap pans instead of emptying; pair with Walk Speed build to reach chests; use a Size Boost
build when opening chests (only stat that affects them; Solar Magnifier and Volcanic Eruption do NOT
affect chest ore size). Geodes: same principles but Geothermal enchant, no Excalibur, fully AFK-able,
and luck DOES affect drops — use the Geode Opening build instead of size boost.
